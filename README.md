# 秋招助理（qiuzhao）Skill — 通用版

一个通用的校招投递管理助手：录入 JD、评估岗位契合度、跟踪投递进度、评估 Offer、面试复盘。
首次使用自动初始化（创建飞书表格结构、引导设置偏好），数据全部存在你自己的飞书账号下，本地只存指针。

## 安装

前提：电脑装了 [Claude Code](https://claude.com/claude-code)，并配置好飞书命令行工具 lark-cli：

```bash
lark-cli auth login   # 用你自己的飞书账号授权（一次性）
lark-cli auth status  # 确认通过
```

把本仓库 clone 到 Claude Code 的技能目录（目标路径的目录名必须是 `qiuzhao`）：

```bash
git clone https://github.com/<仓库所有者>/qiuzhao-skill.git ~/.claude/skills/qiuzhao
```

> 没装 git 也可以：在仓库页面点 Code → Download ZIP，解压后把里面的 `qiuzhao` 目录整个移到 `~/.claude/skills/` 下。

重启 Claude Code，输入 `/qiuzhao` 即可——首次使用会自动进入初始化引导。

## 使用

```
/qiuzhao                    # 总览：投递进度、P0 待办、DDL 提醒（首次自动进初始化）
/qiuzhao 初始化             # 手动触发配置；换电脑时用它接入已有表格
/qiuzhao 录入 [JD原文]      # 录入新岗位：拆解 + 匹配分/策略分 + 优先级
/qiuzhao 更新 [公司+岗位]   # 更新投递状态/备注
/qiuzhao offer [公司+岗位]  # 记录 offer 薪资 + 评估分
/qiuzhao 简历 [粘贴全文]    # 录入/更新简历
/qiuzhao 面试 [录音/转写]   # 面试复盘：评分 + 关键问题 + 改进清单 + 待办
```

## 初始化后会发生什么

- 自动在飞书创建一个「秋招投递管理」多维表格（失败则引导你手动建表贴链接）
- 自动建 **6 张表** + 字段：投递记录 / 简历库 / 个人信息 / 评分规则 / Offer评估 / 面试记录
- 写入默认评分权重
- 交互式询问你的**方向偏好**和**城市偏好**（一次一问），用于生成评分档位；画像可选
- 创建「投递进度看板」仪表盘（7 组件：状态分布 / 优先级 / 评分 / 投递趋势 / DDL 提醒 / 面试评分走势）
- 把 base token、table_id 等保存到 `~/.claude/skills/qiuzhao/config.json`

之后随时改「评分规则」表里的权重即可调整评分——改表不改代码。

## 数据归属

- **业务数据**（投递记录/简历/画像/评分规则）全部在你自己的飞书账号下
- **本地只存指针**（config.json：base token、table_id），不含业务数据
- 手机装飞书 App 可随时查看投递表和看板
- 分发给别人的只有 skill 逻辑本身，任何人的数据都不会随包带走

## 核心设计决策

- **评分双轨**：匹配分（够不够格，客观对照简历）+ 策略分（值不值得，按你的偏好）
- **不设"别投"挡**：评分只用于排序 P0 主攻 / P1 重点 / P2 广撒，Offer 阶段再权衡薪资城市
- **权重放数据里**：评分规则存飞书表，改权重 = 改一条记录
- **硬卡一票否决**：学历/届数/专业等不可逾越项不满足 → 匹配分压至 4 以下
- **数据与认证解耦**：数据归个人账号，每台电脑用自己的授权——换设备不换数据
- **面试复盘闭环**：录音/转写 → 评分 + 改进清单 + 待办，写入面试记录表并关联投递

## 常见问题

**初始化时自动创建失败怎么办？**
在飞书手动创建一个多维表格（空表即可），把链接发给 AI，skill 会解析链接继续。

**想改评分权重？**
直接改飞书「评分规则」表的「权重」列。

**换电脑了？**
重新安装 skill，`/qiuzhao 初始化` 时把原来的表格链接发过来即可接入，数据不丢。

**配置文件丢了？**
config.json 只是指针，丢了重新初始化、贴原表格链接即可恢复。
